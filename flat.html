Copies JSONB values from your uploaded records into named columns. Missing values stay empty. All date fields, including creation and recapture dates, use DATE without a time component. Counts use INTEGER and measurements use NUMERIC. Identifiers, categories and blood pressure stay TEXT. Invalid values become NULL and are listed in the type-error review. Original JSON and the initial text-table backup are preserved. Each row includes its reporting period as a DATE. Leave the period filter empty to browse all periods. Apply types / update copies all pending uploads. Repeating this step skips source rows already flattened; separate workbook snapshots remain separate.
