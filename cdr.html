Two-sheet export

The workbook is saved to local disk first. Sheet 1 and Sheet 2 are converted independently, using the first row as headings. Each download is a plain JSON array of row objects, ready for CDR upload.

Formula cells use Excel’s saved values. Excel errors become empty values and are reported in the status. No database upload is performed on this page.

Runs locally. Keep source workbooks and CDR files private.
